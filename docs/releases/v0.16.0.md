# ontos v0.16.0

The optional Wire profile now has Go and TypeScript implementations. TypeScript
consumers import `@bitspark/ontos-wire`; the Go module is
`github.com/bitspark/ontos/wire/go`. The ground packages retain their frozen
value model, identity and `ontos-codec-v1` bytes.

The optional profile supplies bounded deixis construction/admission, ground
embedding and exact ground recovery. Opaque handles are retained unchanged;
recovery refuses live leaves and performs no export or hydration.

Both languages also provide a [compact native realization](../../wire/NATIVE.md).
Caller-owned factories qualify opaque leaves while ontos owns immutable tuple
capture and ground collapse. Private factory identities prevent foreign tuple
construction from bypassing a runtime's recognition policy. Explicit conversion
to and from the deixis representation retains independent structural budgets.

All published packages use version 0.16.0. Root tag `v0.16.0` and nested tags
`projection/deixis/go/v0.16.0` and `wire/go/v0.16.0` identify the same commit.
The release pipeline verifies installed consumers of both optional modules.
Rust retains the ground/deixis projection; no Rust Wire profile is claimed.

Runtime consumer migration is delivered separately in bitwire, bitruntime and
bitnode. This release neither changes their deployed versions nor implements
Function, Stream or Cell protocols.
